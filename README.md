# 글로벌 투자 지수 대시보드 (MVP)

NASDAQ, KOSPI, WTI 지수를 한 화면에서 확인할 수 있는 웹 대시보드입니다.

## 실행 방법

브라우저 CORS 제한을 피하기 위해 백엔드 크롤러 서버(`server.py`)를 함께 실행해야 합니다.

```bash
python3 server.py
```

그 후 `http://localhost:8000` 접속.

## 포함 기능

- NASDAQ / KOSPI / WTI 카드 표시
- Investing.com 페이지 크롤링 기반 실시간 지수 조회 (`/api/indices`)
- 현재가, 변동폭, 변동률 표시
- 새로고침 버튼으로 실시간 데이터 재조회
- 마지막 업데이트 시각, 조회 상태 메시지 표시
- 일부 종목 실패 시 나머지 종목은 계속 표시
- 전체 실패 시 데모 데이터 자동 폴백
